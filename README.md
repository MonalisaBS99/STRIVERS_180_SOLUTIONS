🎯 My Approach

For each problem, I try to:

1. Understand the problem
2. Identify the underlying pattern
3. Think of a brute-force approach
4. Optimize the solution
5. Implement it in C++
6. Analyze Time & Space Complexity
7. Dry-run and test the solution

«The goal is not just to collect solutions, but to understand the patterns behind them.»
